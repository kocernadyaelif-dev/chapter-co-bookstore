The implementation and materials are prepared for review. An archive does not complete
IU's required sequential assessment process.

## Phase 1

Check your name and understand the concept. Submit 01_Phase1_Concept.pdf first.
It has concise text plus a separate diagram/wireframe page. Paste the concise summary
into PebblePad if required. Preserve the exact submitted copy. Record tutor feedback
and resulting changes. The guideline recommends waiting for feedback (up to seven days).

## Phase 2

Work through the implementation after Phase 1 submission in your assessed process.
Put the actual GitHub URL in GitHubLink.txt and on slide 1. Submit the nine-slide PPTX
and short explanation. Preserve the submitted versions. Submit Phase 2 before Phase 3,
then record feedback and concrete final improvements.

## Phase 3

Re-run tests after your revisions. Personalize the abstract's reflection so it accurately
describes your own work. Submit the two-page abstract PDF, final source ZIP, actual
GitHubLink.txt and Phase 1/2 results again. Complete the affidavit electronically in
myCampus. No affidavit or portal submission has been completed here. Confirm in Atlas.

## Actual GitHub repository

Create a repository in your own account. Do not commit data/ or real customer details.
To restore actual build history from the included bundle (Git required):

```sh
git clone ChapterCo_History.bundle chapter-co-git
cd chapter-co-git
git remote set-url origin https://github.com/YOUR-ACCOUNT/YOUR-REPOSITORY
git push -u origin main
```

Replace the example account/repo with the repository you actually created. Alternatively
upload source through GitHub's UI, which will not retain local commit history. Run
python tools/set_repository.py with your actual URL, verify examiner access, replace
the title-slide URL and re-export the presentation PDF. Do not submit the pending link.
