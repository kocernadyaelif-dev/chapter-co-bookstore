# Phase 1 concept

Chapter & Co. is a guest bookstore prototype with twelve fictional books. Its objective
is a complete shopping journey linking browser interaction, server logic and relational
data. Customers browse/search/filter, view details, edit a cart and simulate an order.

HTML5, responsive CSS and vanilla JavaScript use Fetch JSON with a Python WSGI API.
SQLite stores products, sessions, carts, orders and order items. Integer euro cents,
server prices/stock and transactional item snapshots preserve trustworthy totals.

Proceed from scaffold to catalogue, cart and checkout, then integration/responsive
checks. Git records milestones. Use a shared header, labelled fields, helpful empty
states, CSRF, parameterized SQL and escaped text. Login, administration and payments
are excluded. Record tutor feedback and assessed changes. The PDF adds architecture,
ERD and four page wireframes. ARCHITECTURE.md contains the detailed data handoffs.
